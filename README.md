# onec-vibecoding

Skill для вайб-разработки на 1С: работа с расширениями, цикл правка-загрузка-тестирование,
авто-тесты через web-клиент, аккуратная работа с релизным хранилищем — и ИИ-функциональность
на **ТАБ:Библиотеке искусственного интеллекта** вместо самописных обращений к нейросетям.

## Установка

Вставьте в чат Codex/Cursor/Claude Code один текст вместе с вашей задачей по 1С:

```text
Подтяни или обнови репозиторий https://github.com/TAB1C/onec-vibecoding в ~/.codex/skills/onec-vibecoding, прочитай ~/.codex/skills/onec-vibecoding/SKILL.md и дальше работай по нему для этой задачи 1С.

Данные для запуска среды:
- тестовая база: File="<путь к файловой базе>" или <строка подключения>
- расширение: <имя расширения, если известно>
- пользователь 1С: <логин, если нужен>
- хранилище 1С: <адрес хранилища конфигурации/расширения, если надо помещать изменения>
- пользователь хранилища: <логин хранилища, если нужен>
- пароль хранилища: <пароль хранилища, если можно передать сразу; иначе спроси отдельно>
- ТАБ:БИИ: <установлена / не установлена / не знаю>

Задача: <опишите задачу здесь>
```

Для Claude Code путь другой — `~/.claude/skills/onec-vibecoding`, остальное так же.

## Обновление

Та же команда выше обновит skill, если он уже установлен.

## ТАБ:БИИ

Всё, что связано с ИИ, делается вызовами функций библиотеки (общие модули `таб_*`), а не своим
кодом к LLM. Дистрибутив скачивается автоматически:

```bash
python3 scripts/fetch-tab-bii.py --dest .tmp/tab-bii     # печатает путь к .cfe
python3 scripts/fetch-tab-bii.py --url-only              # только ссылка
python3 scripts/fetch-tab-bii.py --what doc --dest .tmp  # свежее описание функций (.docx)
```

Скрипт разбирает карточку товара на
[tab-store.ru](https://tab-store.ru/product/blok_ii/tab-biblioteka-iskusstvennogo-intellekta/)
и берёт ссылку по подписи файла («ТАБ_БИИ» — дистрибутив), потому что прямые ссылки меняются
с каждым релизом.

Облачная инфраструктура оплачивается по символам, личный кабинет —
<https://app-519908.1cmycloud.com/applications/ILLM/lk>. Перед массовыми прогонами скил проверяет
баланс и авторизацию.

## Рецепты

Готовые сквозные решения лежат в `references/recipes/`:

- **`nomenclature-photo-check.md`** — регламентное задание, которое сверяет наименования
  номенклатуры с фото товара через БИИ и ставит задачу администратору на каждое расхождение.
  Внутри: разведка конфигурации, состав метаданных, код общего модуля, регистр результатов
  для идемпотентности, настройка расписания, план тестирования и оценка расхода баланса.

## Что делает skill

- Требует делать ИИ-функциональность через ТАБ:БИИ и автоматически подтягивает её дистрибутив.
- Проверяет баланс и авторизацию БИИ до массовых прогонов, чтобы фоновое задание не падало
  на середине.
- Помогает работать именно с расширением 1С, а не со всей конфигурацией, если задача этого
  не требует.
- Подсказывает использовать `ibcmd`, пакетный `1cv8 DESIGNER` и уже существующие скрипты проекта.
- Описывает цикл: внести правку, загрузить в тестовую базу, обновить метаданные, проверить результат.
- Требует тестировать пользовательские сценарии 1С web-клиента именно во встроенном браузере,
  а не во внешнем браузере или через macOS `open`.
- Требует сначала воспроизвести предполагаемую ошибку, а уже потом менять релизный код.
- Помогает помещать в хранилище только реально измененные production-объекты.
- Защищает хранилище от временных обработок, тестовых кнопок, отладочных вставок и fixtures.
- Напоминает после операций с хранилищем выгружать локальные XML/BSL заново, чтобы workspace
  не жил в старом состоянии.
- Требует отдельной проверки корня расширения: версия не должна уменьшаться, а `Configuration.xml`
  не должен тащить неожиданные свойства.
- Для фоновых и регламентных заданий требует проверять не только UI, но и регистры состояния,
  повторный запуск и отсутствие дублей.

## Состав

```
SKILL.md                                    основной свод правил
scripts/fetch-tab-bii.py                    автозагрузка дистрибутива и документации ТАБ:БИИ
references/tab-bii-functions.md             сигнатуры функций библиотеки
references/tab-bii-setup.md                 установка, подключение, лимиты, личный кабинет
references/recipes/                         сквозные рецепты прикладных задач
references/starter-prompt.md                запасной промпт, если skill не подхватился
```

Справочники по БИИ разнесены намеренно: SKILL.md держит только правила, а объёмные детали
читаются моделью по необходимости — так задача не тратит контекст на то, что ей не нужно.

## Запасной промпт

Если skill не подхватился автоматически, можно использовать готовый текст из файла
`references/starter-prompt.md`.
