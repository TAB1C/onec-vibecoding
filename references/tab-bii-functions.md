# ТАБ:БИИ — сигнатуры функций

Источник: «ТАБ БИИ. Описание функций библиотеки», вер. 0.30 (16.04.2026).
Свежее описание: `python3 scripts/fetch-tab-bii.py --what doc`.

Общее для всех функций:

- `Документ` — `ДвоичныеДанные`, не более **4 МБ**, форматы **jpg/pdf** (шире — отмечено отдельно).
- Варианты `...Асинх` добавляют `Источник` (ссылка / ИдентификаторФормы / UUID) и `Обработчик`
  (имя экспортной функции — `"таб_ОбщиеФункцииБИИ.ВыполнитьОбработчикРезультата"`,
  `"Справочники.Номенклатура.ВыполнитьОбработчикРезультата"`, метод модуля объекта —
  либо `ОписаниеОповещения`). В фоне и регламентных заданиях бери синхронные.
- Модули с пометкой *(в разработке)* могут отсутствовать или менять сигнатуру.

## таб_КомпьютерноеЗрениеИзвлечениеИнформации

- `ОпределитьЗначимыеРеквизитыДокумента(Документ, СписокПолей)` → `СписокЗначений`, ключи =
  переданные поля. **Основная «определить содержание по скану/фото»**: распознаёт, классифицирует
  и раскладывает в переданную структуру. Только базовые типы (строка, число, булево, дата).
- `ОпределитьЗначимыеРеквизитыДокументаАсинх(Документ, СписокПолей, Источник, Обработчик)`
- `ОпределитьКорректностьЗагруженныхСканов(Документ, ОписаниеКорректныхДанных, ОписаниеНекорректныхДанных)`
  → `Булево`. jpg. Дешёвый предфильтр мусора: описания задаются свободным текстом
  («электрический счётчик» / «животные, пустое содержимое»).
- `РаспознатьВесьТекстСДокумента(Документ)` → `Строка` — весь текст документа.
- `РаспознатьВесьТекстСДокументаАсинх(Документ, Источник, Обработчик)` → `Строка`
- `ПроверитьНаличиеПодписиИПечатиНаДокументе(Знач Документ)` → `Структура`: `ПечатиКонтрагентов`
  (массив структур `НаименованиеКонтрагента`, `ИНН`, `Роль`, `КоличествоПечатей`,
  `КоличествоПодписей`), `НераспознанныеПечати`, `НераспознанныеПодписи`, `ВсегоПечатей`,
  `ВсегоПодписей`. Форматы jpg/png/webp/pdf/docx.
- `ПроверитьНаличиеПодписиИПечатиНаДокументеАсинх(Знач Документ, Знач Источник, Обработчик = "")`
  → `Структура(Подписей, Печатей)`
- `ПроверитьСоответствиеПодписиИПечатиОбразцам(Знач Документ, Знач ОбразецПодписи = Неопределено, Знач ОбразецПечати = Неопределено)`
  → `Структура` с процентом соответствия эталону (не подсчёт, а сверка с образцом).
- `ЗаполнитьОбъектПоДаннымДокумента(Документ, Объект)` → объект (записывать самому).
- `СоздатьОбъектыПоДаннымДокументовПакетно(ПакетДокументов, ТипОбъекта, Источник, Обработчик)`
  → `СписокЗначений` ссылок на созданные объекты.
- `НайтиНарущенияВнутреннегоИВнешнегоЗаконодателстваПоФото(Знач Документ)` *(в разработке)*
  → `Массив` нарушений (`ОписаниеНарушения`, `ТипИсточника`, `ТипНормоакта`,
  `НомерНормативногоАкта`, `ОбоснованиеИзКонтекста`, `ТребуетПроверки`, `УверенностьПривязки`).
  jpg/png, до 6 МБ.

## таб_КлассификацияИКластеризация

- `ОпределитьКатегориюПоДанным(ОписаниеДанных, СписокКатегорий, СистемныйПромт)` → `Строка`,
  одна категория из списка. **Способ получить детерминированный ответ вместо свободного текста**:
  сравнение «совпало / не совпало», разбор обращений, автопростановка вида номенклатуры.
  Чем подробнее `ОписаниеДанных`, тем лучше результат.
- `ОпределитьКатегориюПоДаннымПауза(...)` — то же, с паузой между вызовами, для потоковых прогонов.

## таб_АнализИОбработкаТекста

- `ПеревестиТекст(Текст, Язык)` → `Строка`. Язык свободным текстом («английский», «мандарин»).
- `ОпределитьТональность(Текст)` → `Строка`: позитив / негатив / нейтрально.
- `ОпределитьКраткоеОписание(Текст, ДлинаОписания = 100)` → `Строка`.

## таб_ЭтикаБезопасностьКонтроль

- `ОпределитьНаличиеНежелательногоСодержанияВТексте(Текст)`
- `ИсправитьОшибкиВТексте(Текст)` → `Строка`

## таб_ГенерацияДанных

- `СоздатьОписаниеКОбъекту(Объект, ВидОписания, Контекст)` → `Строка`.
  `ВидОписания`: «маркетинговое» (описание товара) или «вежливое» (сопроводительное письмо);
  `Контекст` — уточнение задачи произвольным текстом.
- `СоздатьДемоДанные(СписокОбъектов, КоличествоОбъектов, ОписаниеХарактераДанных = "")` → `Массив`.
- `СгенерироватьРисунок(ОписаниеРисунка, Модель, КоличествоРисунков, Источник, Обработчик)`
  → `СписокЗначений`. Модели «Взгляд» (креативнее, всегда 4) и «Мастер» (точнее, 1–4).
  Параметры прямо в строке: `::сср 16:9`, `::креатив больше`, `::убрать лес`.
  Локально нужен сервер с «ТАБ:Нейросеть АРТ».
- `ВыполнитьЮнитТестПоТекстуФункции(ИмяИПараметрыФункции)` *(в разработке)* → `ТаблицаЗначений`.

## таб_ПоискИнформации

- `НайтиПоСмыслу(ТипОбъекта, СвойстваОбъекта, Организация)` — семантический подбор элемента
  справочника по набору свойств: номенклатура поставщика в прайсе, автозаполнение ссылочного
  реквизита по контексту формы, связывание объектов при загрузке.
- `НайтиПоСмыслуОбъектыСписком(...)` — то же пакетом.
- *(в разработке)*: `НайтиДубликатыСуществующегоОбъектаПоСмыслу`, `НайтиДублиДоЗаписиОбъекта`,
  `НайтиСвязанныеОбъекты`.

## таб_ПрямаяИнтеграцияСНейросетями

- `СделатьПромптВНейросеть(ТекстПромпта, СистемныйПромпт)` → `Строка`, без данных обучения.
- `СделатьПромптВНейросетьАсинх(ТекстПромпта, Документ, Модель, Организация, Источник, Обработчик)`
  → `Строка`, с учётом обучения. `Модель` — из списка в личном кабинете; `Организация` — код
  ассистента, в разрезе которого проводилось обучение.

## Вызов из конфигурации

Конфигурация должна компилироваться и без расширения, поэтому — через проверку и общий модуль
по имени:

```bsl
Если Метаданные.ОбщиеМодули.Найти("таб_КомпьютерноеЗрениеИзвлечениеИнформации") = Неопределено Тогда
	ВызватьИсключение "Не установлено расширение ТАБ:Библиотека искусственного интеллекта.";
КонецЕсли;
Модуль = ОбщегоНазначения.ОбщийМодуль("таб_КомпьютерноеЗрениеИзвлечениеИнформации");
Результат = Модуль.ОпределитьЗначимыеРеквизитыДокумента(ДанныеФото, СписокПолей);
```
