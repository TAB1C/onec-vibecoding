# ТАБ:БИИ — установка, подключение, лимиты

Расширение конфигурации `.cfe` с функциями ИИ на встроенном языке. Бесплатно; платная часть —
инфраструктура: облако с оплатой по символам либо локальный дистрибутив LLM («ТАБ:ЦА»).
Совместимо с 8.3.18+, с типовыми и самописными конфигурациями, с БСП и без неё.

## Загрузка дистрибутива

```bash
python3 scripts/fetch-tab-bii.py --dest .tmp/tab-bii     # печатает путь к .cfe
python3 scripts/fetch-tab-bii.py --url-only              # только ссылка
python3 scripts/fetch-tab-bii.py --what doc --dest .tmp  # описание функций (.docx)
```

Скрипт разбирает карточку товара
<https://tab-store.ru/product/blok_ii/tab-biblioteka-iskusstvennogo-intellekta/> и берёт ссылку
по видимой подписи файла («ТАБ_БИИ» — дистрибутив). Прямые ссылки `/upload/iblock/<hash>/…`
меняются с каждым релизом — не зашивать и не кэшировать. Дистрибутив держать во временном
каталоге, не в репозитории.

Если вёрстка страницы изменилась и скрипт ничего не нашёл — открыть страницу, скачать вручную,
передать путь к файлу.

## Установка

Конфигуратор: *Конфигурация — Расширения конфигурации* → добавить, оставить только флажок
«Активно» (снять «Безопасный режим» и «Защиту от опасных действий») → *Загрузить конфигурацию
из файла…* → принять изменения структуры.

Предприятие (БСП): *Настройка и администрирование — Поддержка и обслуживание — Печатные формы,
отчёты и обработки — Расширения — Добавить из файла*, снять «Безопасный режим», перезапустить.

Пакетно: `ibcmd infobase config extension create` + `config load --extension=…` + `config apply`
(ключи сверять по `ibcmd help`), либо `1cv8 DESIGNER /LoadCfg <файл> -Extension <имя>`.

## Подключение

Кнопка «Настройки» на форме БИИ.

- **Облако** (по умолчанию): логин и ключ доступа берутся в личном кабинете, вносятся в настройки,
  дальше «Проверить подключение». Там же выбирается модель по умолчанию и оплачивается тариф
  (демо 10 тыс. символов, первый 180 тыс.). Один кабинет можно завести на всю организацию.
  Личный кабинет: <https://app-519908.1cmycloud.com/applications/ILLM/lk>.
- **Локально**: администратор ставит ТАБ:ЦА (мультиагентная нейросеть + балансировщик), в настройках
  указываются адрес сервера, порт (по умолчанию 1082), пользователь и пароль; «Проверить
  соединение» гоняет полный тест. Работает в безопасном режиме, данные не уходят наружу.

Логин и ключ доступа — данные настроек базы: не коммитить и не подставлять в примеры кода.

## Лимиты и расход

- Изображения и документы: **до 4 МБ**, jpg/pdf (у части функций шире). Проверять размер до вызова.
- Расход считается в символах: длинные промпты и большие списки полей стоят денег.
  Для регламентных заданий задавать ограничение объектов за прогон.
- `ПроверитьБалансИАвторизацию()` — перед массовым прогоном; при нехватке останавливаться заранее.
- Отчёт «Динамика использования нейросети» — для прогноза пополнения и контроля нагрузки.

## MCP (доступ нейросети к данным базы)

Входит в состав БИИ. Требуется платформа 8.3.10+, публикация базы на веб-сервере и включённый
OData. Настройка: «Настройки подключения ИИ к базе данных 1С (MCP)» → обработка OData → отдельный
пользователь REST-сервиса → вкладка «Состав»: загрузить метаданные и отметить нужные объекты →
указать путь к веб-публикации, логин и пароль → «Зарегистрировать подключение».
Через публичные сети — только HTTPS. Давать доступ только к тем объектам, которые действительно
нужны.
